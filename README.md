# 🚀 CI/CD Monitoring Dashboard

A web dashboard that monitors GitHub Actions workflows and displays CI/CD pipeline metrics such as total builds, successful builds, failed builds, success rate, and workflow history.

---

## 📖 About

The CI/CD Monitoring Dashboard helps developers visualize GitHub Actions workflow statistics in a clean and interactive dashboard.

Instead of manually checking GitHub Actions logs, users simply enter a repository URL and instantly see build metrics and charts.

---

## ✨ Features

✅ GitHub Repository Analysis

✅ Total Workflow Runs

✅ Successful Builds

✅ Failed Builds

✅ Success Rate

✅ Interactive Charts

✅ Responsive UI

✅ Real-time GitHub API Data

## ⚙️ Installation

Clone the repository

-> git clone https://github.com/yourusername/cicd-dashboard.git

Go into project

-> cd cicd-dashboard

Install dependencies

-> npm install

Start server

-> npm start

Open

-> http://localhost:3000


---

## 🚀 Usage

1. Open the dashboard.
2. Paste any GitHub repository URL.
3. Click Analyze.
4. View workflow statistics.
5. Explore build charts.

---

## 🌐 API Endpoint


GET /api/github/summary?repoUrl=<GitHub Repo URL>


Returns ↪️

- Total Builds
- Successful Builds
- Failed Builds
- Success Rate
